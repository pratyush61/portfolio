# Pratyush Dubey | Portfolio

A personal portfolio website that showcases who I am, the skills I work with, and the projects I've built. It is built with React and Vite, and deployed on Vercel.

**[View Live Site](https://portfolio-jet-ten-jjtyz5uxhe.vercel.app)**

---

## About

I'm a frontend developer who enjoys building clean, responsive and user-friendly web applications. This portfolio is a single place to see my work, my tech stack and how to reach me.

---

## Features

- Responsive layout that works on desktop, tablet and mobile
- Featured projects section with links to live demos and source code
- Theme support with sensible defaults
- Fast load times with a lightweight Vite build
- Clean, component-based React codebase

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

```bash
git clone https://github.com/pratyush61/portfolio.git
cd portfolio
npm install
```

### Run locally

```bash
npm run dev
```

Open the local URL shown in your terminal.

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
